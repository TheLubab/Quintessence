# Frontend runtime

## Shared React

React is not bundled into the app. It ships as generated local ESM in `.build/vendor/react/<version>/` (development and production builds, generated by `bun run prepare:browser-assets` from locked packages) and is served at `/vendor/react/<version>/<mode>/*`, so Quint runs fully offline — no CDN fetch. The version and build mode in the URL are why the server serves these files as `immutable` in every mode, and why a prebuilt `quint` and `bun run dev` on one port cannot poison each other's cache; the shell (`frontend/index.html`) and hashed chunks carry their own cache headers, so nothing unhashed is ever given a `max-age`.

The generated `frontend/.build/vendor/` directory is ignored by Git. Dependency installation and the Nix development shell prepare it; the Nix release build generates it explicitly before building and packaging the frontend. Emoji data is copied from the pinned `emojibase-data` package during the same step.

- An importmap in `frontend/index.html` maps `react`, `react-dom`, and the jsx runtimes to the `/vendor/react/<version>/development/*` URLs (`bun run prepare:browser-assets` rewrites the version on a bump; `scripts/build-frontend.ts` switches the mode to `production` in `dist/`). A preload script in the same file imports them, stores the modules on `globalThis.__esm`, and only then calls `__init` to mount the app — this load order is load-bearing.
- `frontend/externalize-react.ts` is a Bun bundler plugin that replaces those specifiers in bundled code with reads from `globalThis.__esm`. The point is ONE shared React instance across the host app and every applet/widget bundle (which resolve the same importmap); bundling React in would give each its own copy and break hooks.
- `frontend/structured-clone-shim.ts` must be the first import in `frontend/index.tsx`, before any tldraw module loads.
- HMR works across the bundle/vendor boundary; the `import.meta.hot.accept()` in `frontend/externalize-react.ts` is what stops every edit from escalating to a full page reload. See the comment in `frontend/index.tsx` before touching any of this.
